# AI Trip Planner — mobile responsive update

This version adds mobile-only responsive styling and a collapsible navigation menu.
Desktop styling is intended to remain unchanged.

## Run locally
1. Install Node.js (if needed).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.

The original `.env` file was intentionally not included in this archive for security.
If your backend uses environment variables, create your own `.env` based on `.env.example`.
